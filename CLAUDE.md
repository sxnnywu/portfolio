# personal portfolio site

A personal portfolio site. Designs live in Figma, but only the homepage exists
so far — treat it as a starting point for the rough vision, not a full spec.

## Stack (decided)
React + Vite + Tailwind. Not Next.js.

## Pages
- Home
- Experience
- Projects
- Community
- Awards
- Contact

## Planned feature
One backend feature, eventually: a global like button. Anyone can like as many
times as they want; every visitor's likes are summed into a single running
total that is displayed and persists across sessions.

## Working style
- Direct, no fluff. If something's wrong, say so.
- Mobile responsiveness is a must-have.
- Always ask when something feels ambiguous rather than guessing.
- Keep code and designs consistent with each other.
- When making a design or code decision, research industry-standard conventions
  for reference first.
- For design, give 2–3 distinct directions, not micro-variations. Blunt
  feedback is normal; iterate.
- Sunny writes casual lowercase — don't mirror it, don't correct it.
